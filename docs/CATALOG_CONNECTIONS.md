# 合成目录连接能力与多轮选择

新合成目录将连接标签和使用能力分开记录：`attributes.connection` 保留“有线／无线／双模／三模”，`connection_capabilities` 只允许 `wired`、`wireless`。静音 K87（299元）、静音 K98（399元）、办公 K108（359元）在本版合成目录中显式定义支持两种抽象能力。这不是对真实商品或 Bluetooth、2.4GHz、协议数量的声明。

用户要求支持无线时，可匹配显式包含 wireless 的多模商品。缺少能力字段的旧双模／三模记录不能据名称推断无线；旧“无线”标签仍是明确的无线来源。存在能力字段时必须通过严格类型和值域校验。仅有线条件拒绝带无线能力或多模标签的商品；明确“不接受双模／三模”作为独立排除条件，不会被当作正向连接需求。

召回前，PostgreSQL scope 已包含当前店铺、上架、库存、预算、噪声、尺寸、连接能力、键盘类型和排除SKU；词法/向量候选截断与RRF TopK只在该集合内进行。取回时重新核对当前 Catalog Version，工具层再次核验约束。候选名单不是报价，提案创建仍重新读取最新商品。

种子入口仍只插入缺失记录，不修改既有数据。因此旧演示数据库不会自动得到新能力字段。如需为旧商品补充能力，必须单独审核元数据、增加 Catalog Version、重建索引，并让旧候选名单失效。本轮仅使用新的隔离环境，不回填历史库。

购买意图只由本轮用户文本和已验证结构化输入决定，不属于持久偏好。针对一个候选的否定与对另一个候选的购买分别绑定；同一商品的中文／数字序号归一化后冲突必须澄清。模型 Handoff 和工具参数不能授予购买权限，确认、付款许可及 Live 预算许可都不跨 Run 继承。

本修复改变源码指纹。T16-B0旧Policy草案、旧Manifest源码绑定和T15-B1已消费授权不能用于本版本；保留原件，只能以新的环境、Session、价格快照和Policy草案重新准入。本版未进行真实DeepSeek多轮验证。
